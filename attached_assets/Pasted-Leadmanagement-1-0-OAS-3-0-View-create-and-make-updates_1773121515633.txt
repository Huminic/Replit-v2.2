Creating an API Request

To make an API request, you'll need to:

Know the Connect CRM resource(s) required (i.e. Contacts, Leads, LeadSources, CallDetails)
Know which operation you want to execute (i.e. GET, PUT, POST)
Understand the Content-Type and Accept header values supported by the endpoint - notice that the /gateway/v1 endpoints use path versioning with standard Content-Types, while all newer endpoints implement a header versioning strategy - which requires you to specify the version as custom Accept and Content-Type headers
Have your bearer token and API key handy

Example API Request

Here's an example of an API request:

curl -X GET \
'https://api.vinsolutions.com/leads?leadStatus=ACTIVE_NEW_LEAD&userId=129253&dealerid=1' \
-H 'Accept: application/vnd.coxauto.V3+json' \
-H 'Authorization: Bearer {replace with your access/bearer token} \
-H 'Content-Type: application/vnd.coxauto.V3+json' \
-H 'api_key: {replace with your API key}? \
