1. **Identify proposed change**
2. **Check this document** - is it forbidden or requires approval?
3. **If requires approval:**
   - Document the change reason
   - Show mockups/examples
   - Submit to design lead
   - Wait for approval before implementing
4. **If approved:**
   - Update design contracts first
   - Update this document if needed
   - Implement change

# Design Changelog - Nexxus V2

## [V3.0] - 2026-01-21 - Return to Original Design + Enhancements

### Added
- **Main Page:** 4 metric tiles (role-specific) above chat
  - Rationale: Provide at-a-glance KPIs without navigating away from main chat interface
  - Partner metrics: system-level (sub orgs, logins, actions, agent actions)
  - Org Admin metrics: operational (pipeline health, lead source, quality, market demand)
  - Staff metrics: actionable (hot opportunities, buying intelligence, threats, urgency)

- **Insights Page:** Activity tab (moved from header)
  - Rationale: Activity feed was cluttering header; belongs with analytics content
  - Shows lead activity for org with user color-coding

- **Insights Page:** Hunches tab
  - Rationale: AI-generated insights need dedicated space with action buttons
  - Card-based layout with confidence scores and dismiss/action options

- **Insights Page:** Library tab
  - Rationale: Centralized location for all available metrics with trends
  - Grid layout with sparklines and trend indicators

- **RBAC View Switcher:** Dev tool to switch between role views
  - Rationale: Testing role-specific UI was impossible without multiple accounts
  - Keyboard shortcut or dev panel toggle

- **Comprehensive Metadata System:** Component headers, inline locks, validation attributes
  - Rationale: Previous design was bastardized by Claude due to lack of constraints
  - Prevents future design drift through embedded documentation

### Changed
- **Logo:** Removed icon, text only
  - Rationale: Simplified branding, cleaner header

- **Chat Thinking Animation:** Changed to flat rolling wave
  - Rationale: Consistent with minimalist design language

- **Terminology:** "Automa" replaces "Dealer Brain"
  - Rationale: "Dealer Brain" caused confusion; "Automa" is clearer

- **Insights Structure:** Reorganized into Dashboard/Reports/Library/Hunches/Activity
  - Rationale: Better information architecture separating real-time vs historical data

- **Reports Section:** Moved under Insights
  - Rationale: Reports are analytical, belong with Insights

### Removed
- **Insights "Goals" Tab:** Deleted completely
  - Rationale: Feature was not being used and cluttered navigation

- **"Dealer Brain" Terminology:** Removed everywhere
  - Rationale: Confusing, inconsistent with "Automa" naming

- **Automa from Agents Page:** No longer listed
  - Rationale: Automa is system-wide, not a custom agent; listing it was confusing

- **Activity Feed from Header:** Moved to Insights > Activity
  - Rationale: Header was cluttered; activity belongs with analytics

### Locked
- **Navigation Order:** Main, Insights, Agents, Hub, Drive (FIXED)
  - Rationale: This order was in original design contract; cannot change

- **Chat Dialogue Layout:** Bot left, user right, no icons (FIXED)
  - Rationale: Established pattern that users are accustomed to

- **Main Page Tile Grid:** 2x2 layout (FIXED)
  - Rationale: Optimal information density for at-a-glance metrics
