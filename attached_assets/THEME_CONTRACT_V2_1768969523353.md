# Nexxus V2 - Theme Contract

**Version:** 2.0 (Dual-Density + Light/Dark + Mobile-First)
**Last Updated:** January 21, 2026
**Status:** Production Ready
**Classification:** Internal

---

## 🎯 Purpose

This document defines the **complete design token system** for Nexxus V2, including:

- **Dual-density design system** (data tables vs. chat interfaces)
- **Light + Dark mode themes** (both required, not optional)
- **Mobile-first responsive tokens** (breakpoints, spacing, touch targets)
- **ClickUp-inspired patterns** (space efficiency, muted colors, subtle animations)
- **Organization branding** (logo + 2 colors only)

**Key Principle:** This is a **reusable interface architecture**. The theme system is built for future reskinning without code changes.

---

## 📐 Theme Architecture Overview

### What Themes CAN Change
- ✅ Colors (brand, semantic, neutral, backgrounds, foregrounds, borders)
- ✅ Typography (fonts, sizes, weights, line heights, letter spacing)
- ✅ Spacing (margins, padding, gaps)
- ✅ Radius (border-radius values)
- ✅ Shadows (elevation levels)
- ✅ Motion (transition durations, easing functions)

### What Themes CANNOT Change
- ❌ Information architecture (routes, navigation hierarchy)
- ❌ User flows and business logic
- ❌ Component functionality and props interfaces
- ❌ Data models and API contracts
- ❌ Core UX patterns (keyboard nav, drag-and-drop, etc.)

### Color Validation (Server-Side)

```typescript
const validateBrandingColors = (primaryColor: string, secondaryColor: string) => {
  // Must be valid hex colors
  const hexRegex = /^#[0-9A-F]{6}$/i;
  if (!hexRegex.test(primaryColor) || !hexRegex.test(secondaryColor)) {
    throw new Error('Colors must be valid hex format (#RRGGBB)');
  }

  // Must meet WCAG AA contrast requirements (4.5:1 ratio)
  const contrastWhite = calculateContrast(primaryColor, '#FFFFFF');
  const contrastDark = calculateContrast(primaryColor, '#0F172A');

  if (contrastWhite < 4.5 && contrastDark < 4.5) {
    throw new Error('Primary color must have 4.5:1 contrast against light or dark background');
  }
};
```

## ♿ Accessibility Requirements (WCAG 2.1 AA)

### Color Contrast Standards

| Element Type | Contrast Ratio | Example |
|--------------|----------------|---------|
| Normal text | 4.5:1 | Body text on background |
| Large text (18px+) | 3:1 | Headings, large UI text |
| UI components | 3:1 | Buttons, form inputs, icons |
| Focus indicators | 3:1 | Outline/border on focused elements |

### Validation Function

```typescript
const validateContrast = (
  foreground: string,
  background: string,
  fontSize: number,
  fontWeight: number
) => {
  const ratio = calculateContrastRatio(foreground, background);
  const isLargeText = fontSize >= 18 || (fontSize >= 14 && fontWeight >= 700);
  const requiredRatio = isLargeText ? 3 : 4.5;
  return ratio >= requiredRatio;
};
```

## 🛠️ Theme Toggle Implementation

### ThemeProvider Component

```tsx
import { createContext, useContext, useEffect, useState, ReactNode } from 'react';

type Theme = 'light' | 'dark';

interface ThemeContextValue {
  theme: Theme;
  toggleTheme: () => void;
  setTheme: (theme: Theme) => void;
}

const ThemeContext = createContext<ThemeContextValue | undefined>(undefined);

export const ThemeProvider = ({ children }: { children: ReactNode }) => {
  const [theme, setThemeState] = useState<Theme>(() => {
    // 1. Check localStorage
    const stored = localStorage.getItem('nexxus:theme') as Theme | null;
    if (stored) return stored;

    // 2. Check system preference
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      return 'dark';
    }
    
    return 'light';
  });

  // Apply theme to document
  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('nexxus:theme', theme);
  }, [theme]);

  // Listen for system preference changes
  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
    const handleChange = (e: MediaQueryListEvent) => {
      if (!localStorage.getItem('nexxus:theme')) {
        setThemeState(e.matches ? 'dark' : 'light');
      }
    };

    mediaQuery.addEventListener('change', handleChange);
    return () => mediaQuery.removeEventListener('change', handleChange);
  }, []);

  const toggleTheme = () => {
    setThemeState((prev) => (prev === 'light' ? 'dark' : 'light'));
  };

  const setTheme = (newTheme: Theme) => {
    setThemeState(newTheme);
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme, setTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export const useTheme = () => {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme must be used within ThemeProvider');
  }
  return context;
};
```

## ✅ Theme Checklist

### Light Mode Requirements
- [ ] All text meets 4.5:1 contrast ratio against backgrounds
- [ ] Interactive elements have 3:1 contrast
- [ ] Focus indicators visible (3:1 contrast)
- [ ] Brand colors adjusted for light backgrounds
- [ ] Shadows provide subtle elevation

### Dark Mode Requirements
- [ ] All text meets 4.5:1 contrast ratio against dark backgrounds
- [ ] Brand colors lightened (e.g., purple 500 → purple 400)
- [ ] Semantic colors lightened for visibility
- [ ] Shadows adjusted for dark backgrounds
- [ ] Border colors adjusted for dark theme

### Mobile Requirements
- [ ] Touch targets minimum 44×44px
- [ ] Font sizes readable on small screens (min 13px)
- [ ] Spacing adjusted for touch interaction
- [ ] Hamburger menu accessible with one thumb
- [ ] Bottom drawer height comfortable (70% screen)

### Dual-Density Requirements
- [ ] Data tables use 13px font, 1.4 line-height, 8-12px padding
- [ ] Chat uses 14px font, 1.6 line-height, 16-20px padding
- [ ] Clear visual separation between density modes
- [ ] Consistent within each mode

## 🎯 Final Notes

### Critical Requirements
1. ✅ **Both light and dark modes required** — Not optional
2. ✅ **Mobile-first responsive design** — Critical for all breakpoints
3. ✅ **Dual-density system** — Data vs. Chat spacing
4. ✅ **WCAG AA compliance** — Minimum 4.5:1 contrast
5. ✅ **Organization branding limited** — Logo + 2 colors only
6. ✅ **Gradient only on chat input** — Nowhere else
7. ✅ **Muted icon colors** — Avoid "icon crazy"

### Token Usage Guidelines
- **Always use tokens** — Never hard-code colors, spacing, etc.
- **Semantic naming** — `--color-foreground-primary` not `--color-gray-900`
- **Consistent patterns** — Same tokens for similar elements
- **Theme-agnostic components** — Work in both light and dark
