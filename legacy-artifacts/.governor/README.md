# App-local Governor Harness (V2)

This directory contains the authoritative app-local governance harness for nexxus2.2_replit.

Built-in Claude features should be used as helpers inside Governor roles, not as replacements for role ownership.
See the Governor kit document `docs/08-CLAUDE-BUILTINS-INTEGRATION.md` and the Captain prompt pack for the role-to-built-in mapping and usage instructions.
